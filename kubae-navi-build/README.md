# 쿠배내비 V0.1 독립 프로토타입

이 브랜치는 **쿠배내비 화면 캡처/전송 가능성만 검증하기 위한 독립 빌드 공간**입니다.

## 보호 원칙
- rider-jjakkung-app 수정 없음
- 기존 짝꿍내비 코드 수정 없음
- kakao-quickmate-clean 수정 없음
- 이 프로토타입은 별도 package `com.kubaenavi.prototype` 사용

## V0.1 기능
- 한 APK에서 메인폰/보조폰 역할 선택
- 메인폰: Android MediaProjection 화면 캡처
- 메인폰: JPEG 프레임 TCP 송출 (8989)
- 보조폰: 메인폰 IP 연결 후 전체 화면 수신
- 연결 끊김 시 보조폰 자동 재연결

## 현재 단계의 제한
- 동일 Wi-Fi/핫스팟 네트워크에서만 직접 TCP 테스트
- 쿠배 지도 영역 자동 크롭은 다음 단계
- 현재 위치 자동 추적/확대·축소는 다음 단계
- 최종판에서는 기존 짝꿍내비의 페어링/세션/자동재연결 구조와 연결하고 영상 스트림 채널을 분리 예정

## 테스트
1. APK를 두 폰에 설치
2. 메인폰에서 "메인폰 — 쿠배 화면 송출 시작"
3. Android 화면 캡처 허용
4. 쿠팡/배민 화면으로 이동
5. 보조폰에서 메인폰 IP 입력 후 "쿠배 화면 수신"
